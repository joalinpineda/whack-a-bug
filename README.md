# WHACK-A-BUG

A 60-second Halloween QA arcade game built with React, TypeScript, Vite, and custom CSS pixel art.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite (normally `http://localhost:5173`).

## Checks

```bash
npm test
npm run build
```

## How to play

Click bugs as they rise from the graves. Normal bugs score 10, critical bugs 25, rare golden bugs 50, and features cost 20 points. Consecutive bug hits unlock score multipliers. The graveyard gets faster during the shift. High scores persist in local storage.
